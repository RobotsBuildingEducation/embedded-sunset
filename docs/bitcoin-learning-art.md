# Shared Bitcoin artwork

`public/images/bitcoin-learning.svg` is the original, editable illustration used by both Robots Building Education and Piyali/Nosabos. Keep the asset identical in both projects.

**Learning that travels.** An open learning folio contains code, a personal transcript and an achievement seal. A struck brass Bitcoin coin connects learning to community support. Continuous routes join equal peer connection points behind the folio, representing progress and identity that can travel between platforms.

The illustration shares the ethos artwork's forest-green ink, warm paper, sage, ochre and terracotta. Book stitching, page edges, metal engraving and the woven bookmark provide detail without separate decorative stickers. The Bitcoin symbol is drawn as vector paths, with no dependency on a font or icon library.

The transparent SVG uses a 480 × 360 viewBox, without external resources, bitmaps, filters or animation. Both landing pages preserve its 4:3 ratio. Dark mode selects `bitcoin-learning-dark.svg`, using deep teal folio pages, pale sage network lines and warm brass metal on a transparent background. The coding landing uses its localized image label; Piyali treats the drawing as decorative beside the scholarship description.
